## Historias de usuario

**HU-01:** Como administrador quiero ver la lista de productos para conocer el inventario actual.

**HU-02:** Como administrador quiero registrar un producto nuevo para mantener el inventario actualizado.

**HU-03:** Como administrador quiero editar un producto existente para corregir datos incorrectos.

**HU-04:** Como administrador quiero eliminar un producto para retirar artículos descontinuados.

**HU-05:** Como empleado quiero buscar un producto por nombre para encontrarlo rápidamente.

## Criterio de aceptación — HU-01
- **Dado que** el administrador abre `/productos/`
- **Cuando** se carga la página
- **Entonces** ve una lista con el nombre y precio de cada producto.
